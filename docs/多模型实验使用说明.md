# 多模型实验使用说明

## 唯一需要手工完成的配置

打开项目根目录的 `.env.models`，只在以下三个等号后粘贴对应平台的 API Key：

```text
QWEN_API_KEY=
GLM_API_KEY=
KIMI_API_KEY=
```

模型和接口已经配置为：

- Qwen：`qwen-plus`
- GLM：`glm-4.5-flash`
- Kimi：`kimi-k3`
- DeepSeek：`deepseek-chat`（沿用项目原有密钥）

## 在 VS Code 中运行

依次点击“终端 → 运行任务”，先运行“FinQA：全部模型3条连通测试”。四个模型均成功后，再运行“FinQA：全部模型正式实验1147条”。

输出位于 `outputs/multimodel/`。每个平台有独立预测文件和汇总文件，四模型总表为 `outputs/multimodel/summary.csv`。

请勿修改 `models.json`、Top-K 或 Prompt，否则无法保证控制变量一致。正式实验前确认三个平台账户均已开通对应模型并有足够余额。
